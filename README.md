# Optimization for Machine Learning: interactive animations

Interactive animations for a master's course on optimization for machine learning.
Each animation is a standalone web page built with [Plotly](https://plotly.com/javascript/).

**Open them at <https://marcevrard.github.io/ml-animations/>.**

The site follows the course, Modules 1 to 6.

## Animations

### Module 1: Introduction and background

- **[Gradient descent in one dimension](https://marcevrard.github.io/ml-animations/module1/gradient-descent/gradient-descent.html)**

  This page shows gradient descent, $x_{k+1} = x_k - \alpha f'(x_k)$, on $f(x) = (x - 3)^2 + 4$ and $f(x) = e^x - 2x$.
  Sliders set the step size $\alpha$, the start $x_0$, and the iteration $k$.
  Press play to add the iterates one by one.
  The left plot shows the iterates on the graph of $f$.
  The right plot shows their error $|x_k - x^\star|$ on a log scale, with the rate $|1 - 2\alpha|^k \, |x_0 - x^\star|$.
  On the quadratic, the error is multiplied by exactly $|1 - 2\alpha|$ at each step.
  The iterates converge for $0 < \alpha < 1$, alternate around $x^\star$ for $\alpha > 1/2$, and diverge for $\alpha > 1$.
  On $e^x - 2x$, the same factor holds near $x^\star = \ln 2$.
  A checkbox adds Newton's method, which reaches $x^\star$ in one step on the quadratic and converges quadratically on $e^x - 2x$.
  Add `#quad` or `#exp` to the URL to choose the starting function.

## Using the pages

- In the gradient descent page, move the sliders, press play (or the space bar), and tick Newton's method to compare.

- The pages work offline.
  Download or clone the repo and open `index.html` in a browser.
  Keep the folders together, since every page loads the shared `plotly.min.js` from the root.

## Layout

```text
index.html                          landing page, one card per module
plotly.min.js                       Plotly library shared by all pages
module<N>/index.html                the animations of a module
module<N>/<animation>/<page>.html   one folder per animation
```

## How the pages are made

This repo only holds the published pages.
Each page is generated by a Python script, with Plotly, from the course materials, which are kept elsewhere.
Please do not edit the HTML files by hand, since the next update overwrites them.
To report a problem or suggest an improvement, open an issue.
